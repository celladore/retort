# Sync Split PR Workflow

This workflow creates a dedicated branch/commit/PR for files generated by `agentkit:sync`.

## Why

- Keeps generated sync output isolated from feature commits
- Improves review clarity and PR hygiene
- Creates lightweight local usage telemetry for later analysis

## Commands

- PowerShell (default): `pnpm run sync:split-pr`
- PowerShell dry-run: `pnpm run sync:split-pr:dry`
- Bash: `pnpm run sync:split-pr:sh`
- Bash dry-run: `pnpm run sync:split-pr:sh:dry`

## Behavior

1. Validates clean working tree before sync
2. Runs `pnpm --dir .agentkit agentkit:sync`
3. Exits when no changes are produced
4. Creates a dedicated branch (`chore/sync-generated-<utc>`)
5. Commits only sync output with `chore(sync): regenerate generated outputs`
6. Pushes branch and opens a PR back to the current branch by default

## Usage Logging

Both scripts append JSONL events to:

- `.agentkit/logs/tool-usage.jsonl`

Current events:

- `no_changes`
- `dry_run`
- `pr_created`

This is local per-repo telemetry intended to bootstrap broader usage analysis.
