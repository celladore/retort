## Current Blockers

None blocking. One environment gotcha worth knowing:

**This worktree had no `.agentkit-repo` marker.** It is gitignored (`.gitignore:51`), so
it does not travel with a worktree — this is the documented overlay-miss trap from
`.claude/rules/worktree-isolation.md` (root cause of PRs #478/#479). Running
`retort:sync` without it renders `__TEMPLATE__` output. I wrote it manually before
syncing; sync then correctly logged `Using overlay: retort (.agentkit-repo marker)`.
Any future worktree needs the same, or use `retort worktree create`.
