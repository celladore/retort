## Important Correction Made Mid-Session

This branch originally deleted the `dotnet`/`python`/`rust`/`blockchain` domains from `rules.yaml`. **That was wrong and was reverted.**

`filterDomainsByStack` ([template-utils.mjs:1177](../../.agentkit/engines/node/src/template-utils.mjs)) already filters rule domains by language stack, and [synchronize.mjs:705](../../.agentkit/engines/node/src/synchronize.mjs) passes the *filtered* spec to `syncLanguageInstructions`. Proven by syncing `dev`'s full 16-domain spec into an empty tree — the `languages/` output contained no dotnet/python/rust/blockchain.

The files in the repo were **stale orphans from before that filter existed**. Editing `rules.yaml` fixed nothing, broke six `filterDomainsByStack` tests that assert those domains exist, and would have stripped content polyglot repos need — retort's `rules.yaml` is copied near-verbatim into every onboarded repo (docket's is byte-identical modulo line endings).

**Lesson:** to stop a stray rule file, first identify which of the two paths emits it — sync into an empty tmp dir and diff against the repo. Never assume `rules.yaml` is the lever.

## Key Findings

### 1. Two rule-generation paths; only one is gated

| Path | Source | Gating | Output |
|---|---|---|---|
| 1 | `templates/claude/rules/*.md` | **none** — verbatim copy to every repo | `.claude/rules/dotnet.md` |
| 2 | `templates/language-instructions/*.md` | `filterDomainsByStack` | `.claude/rules/languages/dotnet.md` |

Path 1 never consults `rules.yaml`, so no spec change can suppress it. **Still unfixed:** `iac.md` is copied flat even when the filter excludes `iac`.

### 2. Orphan prune is dead code in practice — the root of "sync churn"

`cleanStaleFiles` guards on:

```js
if (!noClean && previousManifest?.files) { ... }
```

`previousManifest` comes from `.agentkit/.manifest.json`, which is **gitignored** (`.gitignore:74`). It is therefore absent in every fresh clone, CI run, and new worktree — so orphan cleanup effectively never runs. Stale output accumulates permanently and the CI drift check cannot see it. This is why 37 dead files sat in the repo.

### 3. Worktree overlay resolution trap

Overlay resolution order is `--overlay` flag → `.agentkit-repo` marker → **project root directory name** → `__TEMPLATE__`. The main repo works without a marker only because its folder is literally named `retort`. Any worktree with a different directory name silently resolves to `__TEMPLATE__` and generates wrong output. Always write `.agentkit-repo` (it is gitignored) before syncing in a worktree.

### 4. Downstream bloat is systemic

`docket` and `PuffWise` both carry the same dotnet/python/rust/blockchain domains despite being TypeScript repos.
