## For adopters

- **Migration tooling:** Choose and set up migration tooling in your project (e.g. **Prisma** or **Drizzle** as referenced in the backlog). Add your chosen tool to `package.json` and configure it in your repo.
- **Basic workflow:** Typical workflow: (1) define or update schema in your tool’s format, (2) generate a migration, (3) run migrations against your target environment(s). Document the exact commands in your repo (e.g. in `docs/engineering/` or README).
- **This repo:** No migration tooling is configured here; the framework does not run or apply migrations.
